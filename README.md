# Farmer-Harris Cell Model Simulation

Python implementation of the Farmer & Harris discrete cell membrane model studying cell migration, deformation, and clustering due to chemotaxis.

## Requirements
* Python 3.13 (64-bit)
* NumPy
* Matplotlib
* FFmpeg (for MP4 animation rendering)

## Running the Cases
Run any self-contained case script to execute the simulation and generate its `.mp4` animation:
```bash
python case1.py
python case2.py
python case3.py
python case4.py
python case5.py
